# Cartografía local

`colombia.geojson` contiene únicamente el contorno simplificado de Colombia para el mapa local de demostración.

- Fuente: Natural Earth, Admin 0 — Countries, escala 1:110m, versión 5.1.1.
- Descarga: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/
- Licencia: datos de Natural Earth en dominio público.
- Transformación: filtro `ADM0_A3 = COL`, simplificación al 35 % y precisión de 0,001 grados.

No contiene rutas operacionales, direcciones, contactos ni datos de personas.
