# Estado comprobado

Fecha: 2026-08-14 · Puerta: G1 sandbox para demostración controlada.

Supabase local y el proyecto remoto sandbox están activos. La base se reconstruyó con once migraciones y datos 100 % sintéticos. Pasan 67 pruebas SQL, la verificación RLS, 6 unitarias, 18 Playwright, lint, TypeScript y build. El esquema público expone necesidades, centros y despachos aproximados mediante proyecciones/RPC seguras; las funciones transaccionales tienen permisos explícitos por rol.

La experiencia pública incluye inicio humano, catálogo de necesidades, MapLibre con cartografía vectorial OpenFreeMap y fallback cartográfico Leaflet/OpenStreetMap, centros y despachos aproximados actualizados por Supabase Realtime, seguimiento, dashboard de cobertura y Excel público seguro. El aliado registra aportes detallados en cinco pasos y obtiene ticket QR. El centro operativo prioriza tareas según rol y puede exportar un libro Excel filtrado por sesión y RLS.

Código: repositorio privado `https://github.com/AndresMupa/ruta-solidaria`. Local: aplicación `http://127.0.0.1:3000`, Studio `http://127.0.0.1:54323`, Mailpit `http://127.0.0.1:54324`.
